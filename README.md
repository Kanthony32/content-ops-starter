# hoopthink.net

Static site for Hoop Think, a Westview Group publication.

- `site/index.html`: homepage with the HoopThink Briefing preview issue and the email signup (Netlify Forms, form name `briefing-preview`)
- `site/briefing/thanks/`: page shown after signup, with the PDF download
- `site/briefing/hoop-think-preview-issue.pdf`: the preview issue

Signups appear in Netlify under Forms > briefing-preview.
The Netlify starter template that used to live here is in git history before this commit.
